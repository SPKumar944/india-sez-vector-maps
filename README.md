## 🎯 Demarcated Plot Intelligence Records

Every demarcated parcel in the viewer contains verified land intelligence records:
* **Survey Plot Number:** (e.g., `Plot A-57`, `Plot 30`, `Plot P-17`, `Plot X-23`)
* **Allottee / Occupant Company:** Registered corporate tenant or Vacant parcel status
* **Plot Area:** Precise area in square meters and converted to acres
* **Zoning Category:** Industrial, Commercial, IT/ITeS, or Utilities
* **Official Tariff:** Rate per sq. meter as recorded in MIDC databases
* **Coordinates:** Precise centroid Latitude and Longitude
